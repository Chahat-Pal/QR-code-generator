# 📱 QR Code Generator

## 📌 Description
A simple Python project that generates QR codes from user input (text or URL) and saves them as an image file.

---

## 🚀 Features
- Generate QR codes instantly
- Supports text and URLs
- Saves QR code as an image file
- Easy to use

---

## ⚙️ How to Run

### 1. Install dependency
```bash
pip install qrcode[pil]
```
### 2. Run the program
python qr_generator.py

### 3. Enter your text or URL

### Example:

Enter text or URL: https://google.com

👉 QR code will be saved as an image file

### 💻 Example Output
Input: https://google.com
Output: QR code image file

### 🛠 Tech Used
- Python
- qrcode library
- PIL (Pillow)
